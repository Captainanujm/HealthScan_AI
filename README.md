# 🩺 HealthScan AI

**HealthScan AI** is a smart health report analyzer built with modern web technologies. It extracts key medical data from PDFs or images using OCR, analyzes it with AI, and provides insightful summaries to users — even sending results directly via email.

---

##  Features

-  Upload health reports (PDF or image)
-  OCR text extraction using **Tesseract.js** / **pdf-parse**
-  AI analysis via **Gemini/GPT**
-  Email summary feature using **EmailJS**
-  Built with **Next.js (App Router)** and **Node.js**
-  Modern UI using **Tailwind CSS** and **ShadCN UI**

---

## 🛠️ Tech Stack

- **Frontend**: Next.js (App Router), Tailwind CSS, ShadCN UI  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **OCR**: Tesseract.js / pdf-parse  
- **AI Integration**: Gemini (or GPT)  
- **Email Service**: EmailJS
